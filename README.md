# Вязаный ковёр

Небольшая браузерная игра в вязаном стиле. Нажимайте на клубки ESM, HR, O, P и Pr: из каждого тянется нитка, и вяжется ковёр с картинкой на выбор: город, рабочий стол или пейзаж. С одним цветом полотно однотонное, с каждым новым цветом в узоре появляются новые детали. Порядок нажатий определяет, какой цвет уйдёт на фон, а какой на детали.

Играть: https://evelinaya.github.io/knitted-city/

Вся игра в одном файле `index.html`, без сборки и зависимостей.
