# Вязаный город

Небольшая браузерная игра в вязаном стиле. Нажимайте на клубки ESM, HR, O и P: из каждого тянется нитка, и вяжется ковёр с городом. С одним цветом полотно однотонное, с каждым новым цветом в узоре появляются новые детали. Порядок нажатий определяет, какой цвет уйдёт на небо, дома и окна.

Играть: https://evelinaya.github.io/knitted-city/

Вся игра в одном файле `index.html`, без сборки и зависимостей.
